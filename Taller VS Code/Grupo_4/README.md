# Reto Git con Visual Studio Code — Grupo 4

**Objetivo:** Corregir un error sencillo, registrar todos los cambios y publicar una rama en GitHub.

## Instrucciones

1. Abran el repositorio del grupo en VS Code. Comprueben que están en `develop`.
2. Ejecuten `programa.py` e identifiquen qué resultado está mal.
3. Si necesitan ayuda, consulten `Solucion.txt` (pueden usarla libremente).
4. Creen desde `develop` una rama llamada **`rama/grupo4`**.
5. Corrijan el error en `programa.py` y comprueben el resultado.
6. Completen `Integrantes.txt` con los nombres de los cuatro integrantes.
7. En **Source Control**, preparen **todos los archivos modificados** (Stage All Changes o `+`).
8. Hagan un commit con un mensaje claro, por ejemplo: `Corrige error del grupo 4 y agrega integrantes`.
9. Presionen **Publish Branch** para publicar **`rama/grupo4`** en GitHub.
10. Comprueben en GitHub que la rama contiene el código corregido y `Integrantes.txt` completo.

**No necesitan hacer merge a `develop`.**

Buscar ana o ANA debe encontrar a Ana.

## Evidencia de entrega

Mostrar al docente la rama `rama/grupo4` publicada en GitHub con el commit y los archivos actualizados.
